
# Declaración de uso de IA

Este archivo registra algunas de las consultas realizadas a herramientas de inteligencia artificial durante el desarrollo del proyecto. La IA fue utilizada como apoyo para resolver dudas técnicas, comprender errores, consultar comandos y orientar algunas decisiones de implementación.

## Registro de consultas

### 16 de septiembre de 2026

*Yuli ChatGPT:

-Consulta: ¿Cómo configurar y utilizar la clave de la API de REST Countries después de crear la cuenta?

Uso: Se recibió orientación para configurar la clave y utilizarla dentro del proyecto, ya que era nueva la api para nosotros.

-Consulta: ¿Cómo evitar dejar la clave de la API directamente en el código?

.Uso: Se recibió orientación para utilizar un archivo `.env` y acceder a la variable desde Vite.
